📚 SDK Methods & Capabilities Cheat Sheet

                    

                        

                            auth.login(user, pass)
                            
Authenticates user credentials and validates motherboard HWID lock.

                        

                        

                            auth.register(user, pass, key)
                            
Creates new user account and binds the license key duration.

                        

                        

                            auth.license(key)
                            
Direct license key login without requiring username/password.

                        

                        

                            auth.var("OFFSET_NAME")
                            
Fetches encrypted cloud variable from server memory (Zero-Leak).
